# スピーチタイマー（呼び鈴）

* 開発背景：
  プレゼンテーション、朝礼のスピーチなど、時間超過を呼び鈴で発表者へそっと教えてあげましょう。複数時間が必要であれば複数実行することも可能。
  <img width="233" height="211" alt="image" src="https://github.com/user-attachments/assets/f71f442a-710f-42aa-9987-f0423fce9021" />


* 開発環境：
  Visual Studio Code
  
* 言語：
  Python

* 利用方法：
  - ①[アプリファイル](https://github.com/CodeWalker-lab/speech_timer/blob/main/speech_timer.exe)（.EXE）をダウンロードする。
  - ②時間を設定する。（MM:SS）または（SSSS）
  - ③開始ボタンを押す。

* 注意事項：
  ※実行時に実行注意メッセージが表示される場合がありますが、安心して実行ください。
  - Windows によって PC が保護されましたMicrosoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC が危険にさらされる可能性があります。
  - 詳細より実行ください。
